山河Linux全称“山河大学Linux操作系统”，是一款基于[NixOS](https://nixos.org)的Linux操作系统发行版，Beta版本于2025年2月在山河大学Linux用户组内部发行，2025年3月开始只发行基本配置，2025年4月1日Shanhe Linux 1.0（x86_64版代号Saber，arm版和mobile版代号Noah）配置正式版发行，但由于诸多原因尚未编写文档。

山河Linux操作系统旨在为用户提供一个稳定、安全、易用的操作系统环境，适合个人用户和开发者使用。本文档将指导您如何安装、配置和使用山河Linux操作系统，并介绍部分软件的安装方法。（部分基于NixOS文档改写，有需要的朋友可在[本文档repo](https://github.com/teamshanhe/cs-public/wiki/issues)中提出建议。 ps. issue的标题请特别标注`山河Linux`）

# 特点介绍

山河大学Linux操作系统是为开发者设计的操作系统，它的定位是提供一个稳定、安全、易用的开发环境，适合个人用户和开发者使用。因为它是基于NixOS开发的，因此拥有以下特点：

## 核心基石：声明式系统配置

与传统Linux发行版通过修改散落在系统各处的配置文件来进行管理的方式不同，本操作系统所采用的基础操作系统NixOS采取了声明式的方法。这意味着您不再需要执行一系列命令来安装软件、配置服务，而是通过编写一个中心化的配置文件（通常是`/etc/nixos/configuration.nix`）来“声明”您期望的系统状态。

在这个文件中，您可以使用专门的、纯函数式的Nix语言来描述整个系统的一切：需要安装的软件包、要启用的系统服务、用户账户、网络设置，甚至是内核参数。当您修改完这个文件后，只需运行一个命令 (`nixos-rebuild switch`)，NixOS就会自动计算出差异，并将系统调整到与您的声明完全一致的状态。

这种“代码即系统 (OS as Code)”的方式带来了诸多好处：

- 集中管理与透明化: 所有系统配置集中于一处，清晰明了，便于版本控制（如使用Git），您可以轻松追踪每一次的系统变更。
- 易于分享和迁移: 您可以将这份配置文件复制到另一台机器上，从而快速复刻出一个几乎完全相同的系统环境，极大地简化了新机器的部署和环境搭建。

## 稳定之源：可重现与隔离的构建

NixOS的另一大基石是其强大的**Nix 包管理器**。Nix的设计哲学保证了软件包构建的**可复现性**。对于任何一个软件包，只要其构建指令（Nix 表达式）和所有依赖项（包括编译器）的版本都完全相同，那么在任何机器上构建出的结果都将是二进制级别的一致。

为了实现这一点，Nix采取了独特的软件包存储方式：

- Nix Store (`/nix/store`): 所有软件包都被安装在`/nix/store`目录下一个以其内容哈希值命名的独立子目录中。例如，特定版本的 gcc 可能会被安装在`/nix/store/s2z...-gcc-11.3.0/`中。

- 无传统目录结构: NixOS摒弃了传统的`/bin, /lib, /usr`等目录结构。系统中的程序通过符号链接和环境变量来找到它们的依赖项，这些依赖项都精确地指向`/nix/store`中的特定版本。

这种机制彻底解决了传统Linux系统中普遍存在的“依赖地狱”问题。不同的程序可以依赖同一个软件的不同版本，而不会产生任何冲突，因为它们各自指向`/nix/store`中相同的路径。

## 无忧升级：原子操作与即时回滚

NixOS的系统更新过程是**原子性的**。当您执行系统更新时，NixOS会在后台构建出新系统的完整环境，包括所有新的软件包和配置文件。只有当所有构建都成功完成后，系统才会切换到新的“世代 (generation)”。如果在构建过程中出现任何错误，系统将保持原状，不会出现“半吊子”的更新状态。

更令人称道的是其强大的**回滚能力**。每一次成功的系统变更都会创建一个新的系统世代。如果新的配置出现问题（例如，某个软件无法启动或系统不稳定），您无需手动排查和修复，只需重启系统，在启动菜单（GRUB）中选择之前的任何一个世代，即可瞬间将系统恢复到那个时间点的状态。这个过程几乎是零成本的，为您大胆尝试新软件、新配置提供了坚实的保障。

## 开发者的福音：纯净与隔离的开发环境

NixOS的特性使其成为开发者的理想选择。通过`nix-shell`或更现代的`nix develop` (配合Flakes使用，系2020年后NixOS基金会新推出的New CLI)，开发者可以为每个项目创建独立的、隔离的开发环境。

您可以在项目的配置文件中声明所有必需的依赖，包括特定的编程语言版本、库、编译器和工具。当进入这个环境后，只有这些声明的依赖是可用的，完全不会污染全局系统环境，也避免了项目间的依赖冲突。这保证了团队中所有成员以及持续集成（CI/CD）服务器都能使用完全一致的开发环境，极大地提升了协作效率和构建的可靠性。

另外还有...

- 12万+软件包官方支持，另有6200+软件包来自[Cachix](https://cachix.org)平台，4600+软件包来自NUR；
- 第4代NixOps支持（NixOps=NixLSP+Nix+NixOS）；
- 支持Flakes和Home Manager等多种高级配置框架；
- 支持x86_64，armv8，i686，powerpcle64，raspberrypi等多种框架；
- ...

总而言之，NixOS通过其声明式的配置、可重现的构建和原子性的升级回滚机制，构建了一个极其稳定、可靠和可控的操作系统。虽然对新手有一定门槛，但一旦掌握，将为系统管理、软件开发和运维部署带来革命性的体验。我们希望山河Linux也能利用NixOS的这些优势，为开发者提供软件开发上的便利。

## 1. 安装系统
> 注意：
>> 安装前先预留**64GB存储空间和最低6GB的RAM**，VMware虚拟机用户在安装完成后还需要安装VMware Tools.
>> 另外需要root权限才可进行安装

首先下载[NixOS镜像](https://channels.nixos.org/nixos-25.05/latest-nixos-minimal-x86_64-linux.iso)
1. 进入系统后先运行以下命令配置网络：

```bash
sudo -i && systemctl start wpa_supplicant && wpa_cli
```

2. 接下来按照以下方法配置您的网络（以连接到名为"myhomenetwork"的无线网络为例）：

```sh
> add_network
0
> set_network 0 ssid "myhomenetwork"
OK
> set_network 0 psk "mypassword"
OK
> enable_network 0
OK
```

3. 完成后请直接运行山河Linux安装脚本程序进行安装：

```bash
bash <(curl -s https://shanheix.github.io/Shanhe-Linux/)
```

> Tips:
>> Shanhe Linux的x86_64版本中有5个风味：
>>> 1. Shanhe Ace: 游戏专门风味版
>>> 2. Shanhe Labs：AI/LLM工程专门风味版
>>> 3. Shanhe Neons：开发者专用风味版
>>> 4. Shanhe：通用版本
>>> 5. Shanhe Lite：轻量版

## 2. 配置系统
安装时会提示您选择风味，根据您的需求选择即可。

另外，您可以在安装中您需要先通过`/etc/nixos/configuration.nix`文件进行系统配置再安装。

安装完成后您仍然可以使用vim/nano等文本编辑器配置该文件，并运行命令

```bash
sudo nixos-rebuild switch
```

以复现配置。

>> ```bash
>> sudo nix-collect-garbage -d
>> // or
